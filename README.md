# Южная грация — детский конкурс хореографического искусства

Одностраничный сайт конкурса.

## Файлы

| Файл              | Назначение                                      |
|-------------------|-------------------------------------------------|
| `index.html`      | Главная страница (логотип, форма, положение)    |
| `polozhenie.pdf`  | Положение о конкурсе (для открытия в новой вкладке) |

## Возможности сайта

- Красивая главная страница с логотипом
- Кнопка **«Положение»** — открывает полный документ в попапе
- Кнопка **«Отправить заявку»** — форма заявки, письма уходят на `gracia_konkurs@list.ru`
- Кнопка **«Наши контакты»** — телефон и почта

## Как разместить на GitHub Pages

1. Создайте новый репозиторий на GitHub (например `yuzhnaya-gracia`).
2. Загрузите в него **оба файла**:
   - `index.html`
   - `polozhenie.pdf`
3. Зайдите в **Settings → Pages**.
4. В разделе **Source** выберите ветку `main` (или `master`) и папку `/ (root)`.
5. Нажмите **Save**.

Через 1–2 минуты сайт будет доступен по адресу:  
`https://ВАШ_НИК.github.io/yuzhnaya-gracia/`

## Важно про форму заявки

Форма использует сервис [Formsubmit.co](https://formsubmit.co).

При **первой** отправке заявки на почту `gracia_konkurs@list.ru` придёт письмо с просьбой подтвердить адрес.  
Нужно один раз перейти по ссылке в том письме — после этого все заявки будут приходить сразу.

## Локальный просмотр

Просто откройте `index.html` в браузере (оба файла должны лежать в одной папке).
